# saltypoolwater.com

One complaint a day. Make it funny.

An open-mic night for petty grievances: every user gets one complaint per day,
written as a **setup + punchline**. Punchlines are hidden in the feed until
tapped. The crowd votes on whether the joke **landed** (or gives it a
**womp womp**), scored in PPM — parts per million, because salt.

## Stack

| Layer     | Tech                                            | Azure resource                    |
|-----------|-------------------------------------------------|-----------------------------------|
| Frontend  | React 18 + Vite                                 | Azure Static Web Apps (Free tier) |
| API       | Azure Functions v4 (Node 18+, managed by SWA)   | Bundled with Static Web Apps      |
| Database  | Cosmos DB for NoSQL (Free tier)                 | Azure Cosmos DB account           |
| Auth      | SWA built-in auth (GitHub/Microsoft providers)  | Included, no extra resource       |
| CI/CD     | GitHub Actions (auto-generated by SWA)          | `.github/workflows/`              |

Estimated monthly cost at hobby scale: **$0** (both tiers are free).
Set a budget alert anyway — see `docs/PROVISIONING.md` step 7.

## Local development

```bash
# 1. Install the Static Web Apps CLI and Functions Core Tools (one time)
npm install -g @azure/static-web-apps-cli azure-functions-core-tools@4

# 2. Install dependencies
cd frontend && npm install && cd ../api && npm install && cd ..

# 3. Run everything (frontend + API + emulated auth)
swa start http://localhost:5173 --run "npm --prefix frontend run dev" --api-location api
```

Open http://localhost:4280. Without Cosmos credentials the API falls back to
an in-memory store, so the site works locally with zero Azure setup.

## Deploying

Follow `docs/PROVISIONING.md`. Short version: create the Static Web App in the
Azure Portal, point it at this GitHub repo, and every `git push` to `main`
deploys automatically.
